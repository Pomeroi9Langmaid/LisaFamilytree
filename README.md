# Lisa Family Tree — Before / After Restorations

Public, shareable static gallery of Lisa's family photographs with draggable before/after sliders.

## Image integrity

The restored files in `images/*-after.*` are copied byte-for-byte from the supplied Magnific outputs. They are not resized, recompressed, regenerated, sharpened, or otherwise modified. `manifest.json` records dimensions, byte sizes and SHA-256 hashes for all source assets.

The web page uses responsive CSS only: on smaller screens the browser scales the display down; on larger screens each comparison grows up to the restored file's native width. The **Open restored full-size** link opens the original stored file directly.
